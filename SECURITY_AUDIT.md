# Практична робота №2
## Захист даних, аудит і hardening «Електронного деканату»

### Мета роботи
Провести аудит безпеки REST API «Електронний деканат», проаналізувати потенційні загрози та вдосконалити захист застосунку.

### Виконані етапи
1. Аналіз безпеки Python-коду.
2. Перевірка залежностей і Docker-образу.
3. Аналіз загроз за методологією STRIDE.
4. Аналіз ризиків відповідно до OWASP Top 10.
5. Внесення змін для підвищення безпеки застосунку.

### Використані технології
- Python і FastAPI
- Docker та Docker Compose
- Nginx і TLS
- Bandit
- pip-audit
- Trivy
- Git

### Результати аудиту
Під час перевірки Docker-образу Trivy виявив приватний TLS-ключ усередині образу.

Було розпочато виправлення конфігурації Docker для виключення конфіденційних файлів зі збірки.

Через нестачу вільного місця на Mac перезбірка Docker-образу не завершилася.

Статус: проблема безпеки залишається невирішеною до успішної перезбірки та повторного сканування.

### Модель загроз STRIDE
| Загроза | Заходи захисту |
|---|---|
| Spoofing | JWT-автентифікація |
| Tampering | Перевірка даних і контроль доступу |
| Repudiation | Аудит подій |
| Information Disclosure | TLS, захист секретів |
| Denial of Service | Обмеження частоти запитів |
| Elevation of Privilege | Рольова модель доступу |

### Матриця ризиків
| Ризик | Рівень | Статус |
|---|---|---|
| Приватний TLS-ключ у Docker-образі | Критичний | Не усунуто |
| Несанкціонований доступ | Високий | Потребує перевірки |
| Вразливості залежностей | Середній | Потребує аналізу результатів сканування |
| Відмова в обслуговуванні | Середній | Потребує тестування |

### OWASP Top 10
Під час аналізу враховано ризики порушення контролю доступу, криптографічних помилок, ін'єкцій, небезпечних конфігурацій, застарілих компонентів та недоліків журналювання.

### Рекомендації
1. Виключити TLS-ключі з Docker build context.
2. Перезібрати Docker-образ.
3. Повторно виконати Trivy-сканування.
4. Перевірити результати Bandit і pip-audit.
5. Перевірити налаштування автентифікації та авторизації.
6. Забезпечити захист конфіденційних даних.

### Висновок
У межах практичної роботи проведено аудит безпеки застосунку «Електронний деканат», розглянуто модель загроз STRIDE та основні ризики OWASP Top 10.

Виявлено критичну проблему з приватним TLS-ключем у Docker-образі. Її усунення потребує завершення перезбірки та повторної перевірки.
